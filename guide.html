Part 5 문제풀이 전략

Step 1: 선택지 먼저 확인

선택지 확인 → 문법문제 vs 어휘문제 구분 → 각각 다른 접근법

문법문제 판별법

  • 선택지가 같은 어근의 다른 품사로 구성 → 품사 문제
  • 선택지가 대명사 종류 → 대명사 문제
  • 선택지가 시제/태가 다른 동사 → 동사 문제
  • 선택지가 접속사/전치사/부사 → 연결어 문제

어휘문제 판별법

  • 선택지가 같은 품사, 다른 뜻의 단어 → 해석으로 풀기
  • 반드시 문장 전체를 정확히 직독직해한 후 답 고르기
품사 문제 (출제 빈도 최다!)

명사 자리

관사(a/an/the) + ______ → 명사
소유격(my/his/the company's) + ______ → 명사
전치사(in/of/for/to) + ______ → 명사
동사의 목적어 자리 → 명사

형용사 자리

관사 + ______ + 명사 → 형용사
be동사 + ______ → 형용사 (보어)
appear/seem/look/remain + ______ → 형용사

부사 자리

______ + 형용사 + 명사 → 부사 (형용사 수식)
be + ______ + 형용사/p.p → 부사
주어 + ______ + 동사 → 부사 (동사 수식)
완전한 문장 + ______ → 부사

동사 문제

시제 판별 단서

단서시제
yesterday, last ~, ago과거 (V-ed)
since + 과거시점, for + 기간현재완료 (have p.p)
next ~, tomorrow미래 (will V)
by + 미래시점미래완료 (will have p.p)
currently, now, at present현재진행 (be Ving)

능동 vs 수동

주어가 행위를 '하면' → 능동 (V/V-s)
주어가 행위를 '당하면' → 수동 (be + p.p)

핵심: 동사 뒤에 목적어가 있으면 능동, 없으면 수동

시제일치 예외 (시간/조건 부사절)

When/If/Once/Unless + S' + 현재V, S + will V
If the budget is approved, the project will begin next month.
예산이 승인되면, 프로젝트가 다음 달 시작될 것이다. (if절은 현재!)

주장/제안/명령/요구 동사 + that절

request/suggest/recommend/insist + that + S + (should) V원형
전치사 vs 접속사 vs 접속부사
전치사 + 명사(구) , S + V
부사절 접속사 + S' + V' , S + V
S + V ; 접속부사, S' + V'

의미별 구분

의미전치사접속사접속부사
~에도 불구하고despite, in spite ofalthough, even thoughhowever, nevertheless
~ 때문에due to, because of, owing tobecause, since, astherefore, consequently
~ 동안duringwhilemeanwhile

빈출 함정! 빈칸 뒤가 명사(구)이면 전치사, S+V(절)이면 접속사!
despite + 명사 (O) / despite + S+V (X)
although + S+V (O) / although + 명사 (X)

토익 하루 3문장 - 직독직해 훈련
영어 어순 그대로 앞에서부터 끊어 읽는 연습입니다. 각 문장의 포인트와 패러프레이징을 함께 학습하세요.

1. We are offering 30% off on any booking made during this open house.

우리는 + 제공할 것입니다 + 30% 할인을 + 어느 예약에 관해서든 + 이뤄진 + 공개일에
1) be Ving : ~하는 중이다 / ~할 것이다
2) N + p.p : p.p된 N (후치수식)
3) make a booking : 예약을 하다
4) during + N : N 동안에
30% off on any booking = a discounted reservation rate

2. Prior to your receiving training on the vehicle you will be assigned to, S + V.

당신이 교육을 받기 전에 + 차량에서 + 너가 배정 받게될,
1) prior to + 명사/Ving : ~전에 (=before)
2) (소유격) + Ving : (~가) Ving하는 것
3) N + (S + V) [후치수식] : S가 V하는 N
4) assign A to B : A를 B에 배정하다

3. This marks Ms. Kim's return to Rolidge Motors, where she began her career after graduating from university.

이는 + 보여준다 + Kim씨의 복귀를 + RM 회사로의, + 이 회사에서 + 그녀는 + 시작했다 + 직장생활을 + 졸업한 후
1) mark : 표시하다; (~일 것임을) 보여주다
2) 명사(장소) + where + S'+V' : S'가 V'한 명사
3) after + Ving : Ving한 후
4) graduate (from + N) : (N을) 졸업하다
after graduating from university = after finishing university

4. Please note that children must be at least six years old to tour the farm.

알려드립니다 + 아이들(어린이)은 + 최소 6살이어야만 합니다 + 견학하기 위해서는 + 농장을
1) Please note that S+V : S가 V라는 것을 알려드립니다
2) must + V(동사원형) : V해야 한다
3) at least + 숫자 : 최소 ~
4) 문장 중간에 toV : toV하기 위해서

5. Ms. Kim is reviewing the training manual to see if updates are needed.

Ms. Kim은 + 검토하는 중이다 + 교육 매뉴얼을 + 확인하기 위해서 + 업데이트가 필요한지 아닌지를
1) be Ving : Ving하는 중이다
2) toV : toV하기 위해서
3) see if(=whether) S + V : S가 V인지 아닌지를 확인하다
4) be + p.p [수동태] : p.p되다
review = examine = check

6. Ms. Kim succeeds Mr. Walter, who has served for ten years and is retiring.

Kim씨는 Walter씨의 뒤를 잇는다 + Walter는 + 일해왔다 + 10년동안 + 그리고 은퇴를 할 것이다.
1) succeed + N : ~의 뒤를 잇다 (cf. succeed in ~ : ~에서 성공하다)
2) 명사 + (who + V) : V하는 명사
3) has/have p.p : p.p해왔다, p.p했다 [현재완료]
4) for + 숫자(기간) : ~동안
5) be Ving : Ving할 것이다 [미래]
serve = work
for ten years = for a decade

7. No one without a pass will be granted admission to the conference.

어느 누구도 + 출입증이 없는 + 승인 받지 않을 것이다 + 입장을 + 회의장으로의
1) no + N + V : 어떤 N도 V하지 않다
2) without + N : N없는, N없이
3) grant sb sth [4형식] : sb에게 sth을 승인해주다
→ sb be granted sth : sb는 sth을 승인받다
grant = allow = permit

8. The Ford Group's proposed advertising campaign is by far the most innovative we have seen so far.

Ford Group의 제안된 광고 캠페인은 + 단연코 + 가장 혁신적인 (캠페인이다) + 우리가 지금까지 봤던 (것 중에)
1) 소유격 + p.p + 명사(N) : ~의 p.p된 N
2) by far (=easily) : 단연코 (최상급 강조)
3) the most + 형용사/부사 : 가장 ~한/~하게
4) N + (S + V) [후치수식] : S가 V하는 N
5) so far = (up) to date = yet : 지금까지

9. Residents will not be able to access the building's wireless network, nor will it be possible for them to contact our management staff.

입주민들은 + 접속할 수 없을 것이다 + 건물의 무선 네트워크에, + ~도 가능하지 않을 것이다 + 그들이 + 관리팀에 연락하는 것이
1) will be able toV : toV할 수 있을 것이다
2) S + V(부정문), nor + V' + S' [도치] : S는 V하지 않고, S'도 V'하지 않다
3) It + V + for N(toV의 주체) + toV : N가 toV하는 것은 V하다
contact = reach = call

해당 문장이 나오기 전부터 대화 내용에 집중해야 합니다.
  • What does the man/woman imply when he/she says, "문장"?
  • What does the man/woman mean when he/she says, ~?
  • Why does the speaker say, "문장"?

2) 그림/도표 문제

"Look at the graphic."으로 시작하는 질문
선택지에 나와있는 단어들을 제외한 부분에 집중! → 그 부분에서 정답 단서가 나옴
  • Look at the graphic. Which month do the speakers agree to discuss?
  • Look at the graphic. Which theater was the speaker in yesterday?
  • Look at the graphic. Which building does the speaker talk about?
영어 문장 해석 3원칙
1. 주어(S) + 동사(V) 찾기
2. 동사 뒤 구조 예측하기
3. 후치수식 파악하기 (12가지)

후치수식 12가지 패턴

패턴예시
명사 + 전치사구people with master's degrees
명사 + Ving~employees violating rules
명사 + p.p~a delegate sent to the meeting
명사 + who/which/that + Vthose who share data
명사 + whose + N + Vthe firm whose offices are...
명사 + toVthe ability to communicate

직독직해 연습

People / with master's degrees / are qualified / for the research position.
사람들은 / (석사 학위를 가진) / 자격이 있다 / (연구직에 대한)
A delegate / sent to the meeting / gave / an impressive speech.
한 대표자는 / (회의로 보내진) / 했다 / 인상적인 연설을
Mr. Kim's experience / makes / him / qualified / for the job.
김씨의 경험은 / 만든다 / 그를 / 자격 있도록 / 그 직업에 대한
토익 고득점의 핵심: 직독직해(RC) + 직청직해(LC)

토익 강의

RC 고득점 3가지 조건

1. 문장을 잘 해석할 수 있는가?

  • 단어 암기 + 직독직해 능력
  • 영어 어순 그대로 앞에서부터 끊어 읽기

2. 정답의 근거를 지문에서 찾을 수 있는가?

  • 정답은 반드시 지문에서 찾기 (감/추측 절대 X)
  • 정답이 패러프레이징(같은 뜻, 다른 표현)되어 있는 경우가 많음
지문: "order a replacement" → 선택지: "place an order"
지문: "boost our sales" → 선택지: "Store sales will increase"

3. 문법 빈출 유형을 알고 있는가?

문법문제의 60% 이상을 차지하는 4가지 핵심 파트:
1) 인칭/소유/재귀 대명사
2) 품사 (명사, 형용사, 부사)
3) 동사 (시제, 능동/수동, 수일치)
4) 전치사 vs 부사절접속사 vs 접속부사
LC 고득점 3가지 조건

1. 성우의 말을 이해할 수 있는가?

  • 리딩 실력: 단어/표현 + 직독직해
  • 리스닝 실력: 발음 + 연음 + 말 속도 + 직청직해

2. 질문/선택지를 잘 읽고 정답을 고를 수 있는가?

  • Part 3/4: 질문/선택지에서 모르는 단어가 없도록 평소 암기+해석 연습

3. 집중력 유지 & 미련 버리기

Part 5 문제풀이 전략

Step 1: 선택지 먼저 확인

선택지 확인 → 문법문제 vs 어휘문제 구분 → 각각 다른 접근법

문법문제 판별법

  • 선택지가 같은 어근의 다른 품사로 구성 → 품사 문제
  • 선택지가 대명사 종류 → 대명사 문제
  • 선택지가 시제/태가 다른 동사 → 동사 문제
  • 선택지가 접속사/전치사/부사 → 연결어 문제

어휘문제 판별법

  • 선택지가 같은 품사, 다른 뜻의 단어 → 해석으로 풀기
  • 반드시 문장 전체를 정확히 직독직해한 후 답 고르기
품사 문제 (출제 빈도 최다!)

명사 자리

관사(a/an/the) + ______ → 명사
소유격(my/his/the company's) + ______ → 명사
전치사(in/of/for/to) + ______ → 명사
동사의 목적어 자리 → 명사

형용사 자리

관사 + ______ + 명사 → 형용사
be동사 + ______ → 형용사 (보어)
appear/seem/look/remain + ______ → 형용사

부사 자리

______ + 형용사 + 명사 → 부사 (형용사 수식)
be + ______ + 형용사/p.p → 부사
주어 + ______ + 동사 → 부사 (동사 수식)
완전한 문장 + ______ → 부사
함정! 부사는 없어도 문장이 완전함. 빈칸을 빼고 문장이 완전하면 부사!
동사 문제

시제 판별 단서

단서시제
yesterday, last ~, ago과거 (V-ed)
since + 과거시점, for + 기간현재완료 (have p.p)
next ~, tomorrow미래 (will V)
by + 미래시점미래완료 (will have p.p)
currently, now, at present현재진행 (be Ving)

능동 vs 수동

주어가 행위를 '하면' → 능동 (V/V-s)
주어가 행위를 '당하면' → 수동 (be + p.p)

핵심: 동사 뒤에 목적어가 있으면 능동, 없으면 수동

시제일치 예외 (시간/조건 부사절)

When/If/Once/Unless + S' + 현재V, S + will V
If the budget is approved, the project will begin next month.
예산이 승인되면, 프로젝트가 다음 달 시작될 것이다. (if절은 현재!)

주장/제안/명령/요구 동사 + that절

request/suggest/recommend/insist + that + S + (should) V원형
전치사 vs 접속사 vs 접속부사
전치사 + 명사(구) , S + V
부사절 접속사 + S' + V' , S + V
S + V ; 접속부사, S' + V'

의미별 구분

의미전치사접속사접속부사
~에도 불구하고despite, in spite ofalthough, even thoughhowever, nevertheless
~ 때문에due to, because of, owing tobecause, since, astherefore, consequently
~ 동안duringwhilemeanwhile

빈출 함정! 빈칸 뒤가 명사(구)이면 전치사, S+V(절)이면 접속사!
despite + 명사 (O) / despite + S+V (X)
although + S+V (O) / although + 명사 (X)

Part 6 문제풀이 전략

3가지 문제 유형

  • 문법문제 - Part 5와 동일한 접근
  • 어휘문제 - 문맥 파악 후 해석으로 풀기
  • 문장삽입문제 - 가장 까다로움! (세트당 1문제)

문장삽입문제 풀이법

1. 빈칸 앞뒤 문맥 파악 (앞 문장 + 뒤 문장)
2. 선택지에 대명사가 있으면, 그 대상이 앞 문장에 있는지 확인
3. 전체 흐름과 자연스럽게 연결되는 문장 선택
Part 6는 처음부터 직독직해하며 읽다가 빈칸이 나올 때마다 그때그때 풀기!

Part 7 단일지문 전략

Step 1: 지문 종류 파악

  • 굵은 글씨, 눈에 띄는 부분만 빠르게 스캔 → 어떤 종류의 글인지 추측

Step 2: 질문에서 키워드 뽑기

  • 2~3문제씩 키워드를 뽑은 후 지문에서 근거 찾기
  • 정답의 근거 문장은 보통 질문 순서대로 등장
답을 고를 때 가장 중요한 것: 나의 감이 아닌 지문에서 정답의 근거가 되는 문장을 직접 손으로 가리킬 수 있어야 합니다.
Part 7 이중/삼중지문 전략

처음부터 쭉~ 내용을 연결하며 읽어나가기

4단계 접근법

1단계: 각 지문의 종류/유형 확인

  • 이메일, 기사, 광고, 웹페이지, 차트 등 → 질문에서 언급될 수 있음

2단계: 지문끼리 연관성 파악

  • 각 지문의 굵은 글씨 + 첫 1~2문장만 읽고 스토리 추측
  • 지문 간 연결 포인트가 반드시 존재!
지문1: Web page (Tour 1~5 목록) + 지문2: Review (별 다섯개)
추측: "투어 회사의 여러 투어 중 하나를 이용하고 후기를 남겼구나!"

3단계: 단일문제 vs 연계문제 구분

  • 이중지문: 5문제 중 1~2문제가 연계문제
  • 삼중지문: 5문제 중 2문제가 연계문제
  • 각 질문 옆에 근거 지문 번호 적기

4단계: 스토리를 연결하며 읽기

이중/삼중 지문은 버리는 부분 없이 모든 내용을 머릿속에 넣기!
내가 기억할 수 있을 만큼만 읽고 → 문제풀이 시도 → 이어서 읽기
경험이 쌓이면 "어! 이거 연계문제 냄새!" 하는 감이 생깁니다.
